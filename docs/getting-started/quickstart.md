# Quickstart

Start with the [installed-package walkthrough](provider-neutral-quickstart.md). From an
empty project it shows a complete manifest, registry loading, runtime context, handler,
lexical discovery and ordinary mocked tool execution. No checkout or provider key is
required.

The same guide runs the complete dependent read/prepare customer example and explains
approval requirements. See [repository development](../development.md) only when
changing the framework itself.
